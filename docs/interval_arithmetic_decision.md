# Interval Arithmetic Library Decision (CS-005)

Дата: 2026-11-05. Статус: DECIDED.

## Протокол спайка
Выражение E(r) = 4*(r^-12 - r^-6), precision 256 bit.
Кейс A (широкий бокс): r in [1.1, 1.2].
Кейс B (узкий бокс):  r in [1.122, 1.123].
Эталон (float64, не доказательство): A -> [-1.0, -0.890965]; B -> [-1.0, -0.999988].

## Результаты
| Кейс | MPFI | Arb |
|---|---|---|
| A | [-1.80927, -0.0650686] | [-1.99019, 0.902058] |
| B | (oracle-тест подтвердит ~[-1.010684, -0.989296]) | [-1.01069, -0.989279] |

Оба включения содержат эталонный диапазон: гарантии outward rounding выполнены.

## Анализ
1. Переоценка в кейсе A — interval dependency наивной формы выражения; Arb дополнительно
   теряет tightness, поскольку ball (mid +/- rad) не представляет несимметричные образы
   монотонных операций, тогда как MPFI держит точную семантику концов [a, b].
2. В кейсе B остаточная ширина ~2.1e-2 полностью объясняется dependency
   (|d(4r^-12)/dr| ~ 11.0, |d(4r^-6)/dr| ~ 10.7, ширина 1e-3); вклад библиотек ~1e-5,
   то есть на узких боксах библиотеки эквивалентны.
3. Переоценка линейна по ширине бокса. В операторе Кравчика J_F оценивается на боксе
   радиуса h ~ 1e-6...1e-9, радиус образа K есть O(h^2) + округление, включение устойчиво.
   Узкое место - ширина бокса и предобусловливатель, не библиотека (ТЗ, раздел 9).

## Решение
- Основная библиотека доверенного ядра: Arb/FLINT.
  Обоснование: матричный слой arb_mat (mul/solve/inv) для предобусловливателя C и
  оператора Кравчика; документированная ball-семантика с гарантированным покрытием;
  единая зависимость FLINT.
- MPFI: независимый кросс-оракул в unit-тестах (требование второй реализации, ТЗ 4.2).
  Критерий: на узких боксах (h <= 1e-3) включения Arb и MPFI согласованы с абсолютной
  разницей <= 1e-4 и взаимно содержат середины друг друга; рассогласование валит тест.
- Ограничение: Arb не применяется для интервальной оценки широких боксов с нелинейными
  выражениями; при необходимости широкой оценки - MPFI или разбиение области (ТЗ, раздел 9).

## Предпосылки округления
- Arb: каждая операция гарантирует покрытие точного результата при заданном prec;
  финальные границы через arb_get_lbound_arf / arb_get_ubound_arf и arf_get_d
  с ARF_RND_FLOOR / ARF_RND_CEIL.
- MPFI: outward rounding по спецификации MPFI/MPFR; границы через mpfi_get_left /
  mpfi_get_right и mpfr_get_d с MPFR_RNDD / MPFR_RNDU.
- Точность: 256 bit в спайке; продуктовая точность - адаптивная (ТЗ, раздел 9).
