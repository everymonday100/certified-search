# Interval Arithmetic Library Decision (CS-005)

Дата: 2026-11-05. Статус: DECIDED.

## Постановка спайка
Оценка включения E(r) = 4*(r^-12 - r^-6) на r in [1.1, 1.2], precision 256 bit.
Библиотеки: MPFI (классические интервалы [a,b]) и FLINT 3.x c Arb (ball arithmetic).

## Результаты
- MPFI: E in [-1.80927, -0.0650686]
- Arb:  E in [-1.80927, -0.0650686] (совпадение с точностью до последних знаков)
- Истинный диапазон (float64-эталон): [-1.0, -0.890964]
- Оба включения корректны (содержат истинный диапазон) и оба переоценены
  из-за interval dependency problem в наивной форме выражения.

## Выводы
1. Переоценка определяется формой выражения и шириной бокса, а не библиотекой.
   В операторе Кравчика радиус X ~ 1e-8..1e-12, поэтому член зависимости
   пренебрежим; проверка на узких боксах переносится в CS-010/CS-011.
2. API: MPFI — прямые интервалы, но многословное извлечение границ;
   Arb — ball arithmetic, точечные arf-концы, явный prec в каждой операции.
3. FLINT даёт линейную алгебру, нужную для предобусловливания и
   интервального LDL^T в следующих задачах.

## Решение
- Основная библиотека доверенного ядра: **Arb/FLINT**.
- MPFI оставляется как **независимый кросс-оракул** в unit-тестах:
  на референсных фикстурах интервалы двух библиотек обязаны быть
  согласованы (взаимное покрытие), иначе тест падает.
  Это реализует требование ТЗ о второй независимой реализации
  для критических алгоритмов без написания второго верификатора целиком.

## Предпосылки округления
- MPFI: outward rounding согласно спецификации MPFI/MPFR.
- Arb: гарантированное покрытие точного результата (семантика ball).
- Конвертация в double при выдаче границ: ARF_RND_FLOOR / ARF_RND_CEIL (наружу).
